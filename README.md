# 도시락 알람 (DosirakAlarm)

매일 아침 8시 55분에 "도시락 챙기기"를 알려주는 안드로이드 알람 앱입니다. 앱이 꺼져 있거나 화면이 잠겨 있어도 알람이 울리도록 설계되었습니다.

자세한 기획 배경은 `도시락알람_기획서.md`를 참고하세요.

## 1. 준비물

- [Android Studio](https://developer.android.com/studio) (최신 버전, 무료)
- 알람을 설치할 안드로이드 휴대폰 (또는 에뮬레이터로 먼저 테스트 가능)

## 2. 여는 방법

1. Android Studio를 실행합니다.
2. `Open` → 압축 해제한 `DosirakAlarm` 폴더를 선택합니다.
3. 처음 열면 Gradle Sync가 자동으로 진행됩니다 (인터넷 필요, 몇 분 걸릴 수 있음). 완료될 때까지 기다립니다.
4. Sync 중 "Gradle Plugin/Kotlin 버전을 업데이트하라"는 팝업이 뜨면, 일단 무시하고 그대로 진행해도 됩니다. (버전은 안정적으로 동작하는 조합으로 이미 맞춰두었습니다.)

## 3. 실행/설치 방법

1. 휴대폰을 USB로 연결하고, 휴대폰 설정에서 "개발자 옵션 → USB 디버깅"을 켭니다.
   - 개발자 옵션이 안 보이면: 설정 → 휴대전화 정보 → 빌드 번호를 7번 연속 탭하면 활성화됩니다.
2. Android Studio 상단의 기기 선택 드롭다운에서 연결된 휴대폰을 선택합니다.
3. 초록색 ▶ (Run) 버튼을 누르면 빌드 후 자동으로 휴대폰에 설치되고 실행됩니다.
4. 이후에는 USB 없이도 휴대폰에 설치된 "도시락 알람" 앱 아이콘으로 바로 실행할 수 있습니다.

USB 연결이 어려우면, Android Studio에서 `Build → Build Bundle(s) / APK(s) → Build APK(s)`로 APK 파일을 만든 뒤, 그 APK 파일을 휴대폰으로 전송해서 직접 설치(사이드로드)해도 됩니다. (설치 시 "출처를 알 수 없는 앱" 허용이 필요할 수 있습니다.)

## 4. 앱 사용법

1. 앱을 열고 "오전 8:55 알람" 스위치를 켭니다.
2. 안드로이드 13 이상이면 알림 권한을 한 번 허용해줍니다.
3. 이제부터 매일 8시 55분에 화면이 켜지며 전체 화면 알람이 울립니다.
4. 도시락을 챙기고 "도시락 챙겼어요"를 누르면 기록되고, 상황이 안 되면 "5분 뒤 다시 알림"을 누릅니다.
5. 8:55까지 기다리지 않고 바로 확인하고 싶다면 메인 화면의 "지금 테스트 알람 울리기" 버튼을 누르면 됩니다.

## 5. 알람이 더 확실하게 울리도록 설정하기 (권장)

제조사(삼성, 샤오미 등)의 배터리 절전 기능이 강하면 알람이 늦게 울리거나 안 울릴 수 있습니다. 설치 후 아래 설정을 한 번 해두는 것을 권장합니다.

- 설정 → 배터리 → 앱별 배터리 사용량 → "도시락 알람" → 배터리 사용 최적화에서 **제외(무제한 허용)**
- 설정 → 앱 → "도시락 알람" → 알림 → **모두 허용** (특히 전체 화면 알림/헤드업 알림)
- (삼성 기기) 설정 → 배터리 → 절전되지 않는 앱 → "도시락 알람" 추가

## 6. 프로젝트 구조

```
app/src/main/java/com/dosirak/alarm/
├── MainActivity.kt      메인 화면 (알람 on/off, 기록 확인)
├── AlarmActivity.kt      알람이 울릴 때 뜨는 전체 화면
├── AlarmReceiver.kt      알람 시각에 시스템이 호출하는 브로드캐스트 리시버
├── AlarmScheduler.kt     AlarmManager로 알람을 예약/취소하는 로직
├── BootReceiver.kt       재부팅 후 알람 재예약
├── DosirakApp.kt         알림 채널 생성
├── Prefs.kt              알람 상태 및 체크 기록 저장 (SharedPreferences)
└── Messages.kt           랜덤 응원 메시지 목록
```

## 7. 참고 사항

- 이 앱은 서버 없이 휴대폰 안에서만 동작합니다 (인터넷 연결이 없어도 알람은 정상 작동).
- 개인 사용을 전제로 만들어져 플레이 스토어에 올리지 않고 직접 설치하는 방식입니다.
- 코드는 Android Studio에서 정상적으로 빌드되도록 표준 API 위주로 작성했지만, 실제 컴파일은 Android SDK가 있는 환경(Android Studio)에서만 확인할 수 있었습니다. Gradle Sync나 빌드 중 오류가 보이면 캡처해서 알려주시면 바로 고쳐드리겠습니다.
